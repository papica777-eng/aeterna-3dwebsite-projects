Ultra-modern, high-conversion single-page website for **Immersion Mixed Martial Arts** in Melbourne (Glen Waverley HQ & Ringwood Academy).

Built entirely with clean semantic HTML5, embedded CSS3 (glassmorphic design system), and Vanilla JavaScript (ES6+), featuring zero external build steps or dependencies.

---

## 🥋 Key Features & Interactive Modules

1. **Sticky Top Trust Bar & Glass Header**:
   - Live location indicators (**Glen Waverley HQ** at `655c Waverley Rd` & **Ringwood Academy** at `60 Charter St`).
   - 4.9★ Google Rating (269+ verified reviews), zero-ego beginner friendly badge, and direct call hook [`0491 570 069`](tel:0491570069).
   - Responsive glass header with pulsing CTA.

2. **Split-Screen High-Impact Hero**:
   - 4 key trust checkmarks (100% Free Intro Trial Class, No Lock-In Contracts, Dedicated Beginner Classes, Separate Kids & Adult Programs).
   - Floating glass cards showcasing 5+ Resident BJJ Black Belts and 4.9★ community reputation.

3. **30-Second Class & Goal Matcher**:
   - Interactive 3-step recommendation engine matching age, primary goal, and preferred suburb.
   - Live recommendation card displaying coach assignments, class times, and gear instructions.
   - 1-click Free Trial pre-fill and smooth scroll.

4. **Mobile-First Filterable Timetable Hub**:
   - Seamless location switcher tabs (**Glen Waverley** vs. **Ringwood**).
   - 5 discipline filter pills (**All**, **BJJ Gi/No-Gi**, **Muay Thai Kickboxing**, **MMA & Wrestling**, **Kids & Teens 4–14**).
   - Real schedule times (6:00 AM dawn patrol, 12:00 PM midday, 4:15 PM kids, 6:00–8:00 PM evening grappling & striking).
   - **Interactive Slot Booking**: Clicking any class card automatically pre-selects the class, location, and day in the Free Trial form.

5. **6-Row Direct Comparison Matrix**:
   - Honest side-by-side comparison between Immersion MMA standards and typical Melbourne combat gyms.

6. **4 Core Programs Bento Grid & Real Coaches**:
   - BJJ, Muay Thai, MMA & Wrestling, and Kids Martial Arts (4–7 & 8–14).
   - Featuring Head Coach **Dave Marinakis** (3rd Degree BJJ Black Belt & ADCC World Vet), **Coach Mee** (Head Muay Thai), **Sam (Sammy)**, **James Fitzgerald**, and **"The Three Bens"** at the front desk.

7. **Floating "Ben — Front Desk Concierge" Widget**:
   - Interactive conversational chat widget with 4 quick-prompt chips and intelligent keyword matching.

8. **Dual-Location Schema.org JSON-LD Microdata**:
   - Structured data for `SportsActivityLocation`, `SportsClub`, `ExerciseGym`, `GeoCoordinates`, `AggregateRating`, and `FAQPage`.

## 🚀 Deployment & Local Preview

Because this project is self-contained with zero build dependencies, you can open `index.html` directly in any web browser, or serve it with any static HTTP server:

```bash
# Python
python -m http.server 8080

# Node (npx)
npx serve .
```
